# Оценка свободных ресурсов на виртуальной машине (Linux)

Ниже приведены основные команды для анализа ресурсов на Linux‑ВМ.
echo "== $(hostname)"; . /etc/os-release; echo "OS: $PRETTY_NAME"; \
echo "CPU: $(nproc) vCPU, $(grep -m1 'model name' /proc/cpuinfo | cut -d: -f2)"; \
echo "AVX: $(grep -o -w -E 'avx2|avx512f' /proc/cpuinfo | sort -u | tr '\n' ' ')"; \
free -h | awk '/Mem/{print "RAM: "$2" всего, "$7" доступно"}'; \
df -h / /var 2>/dev/null | awk 'NR>1{print "Диск "$6": "$2" всего, "$4" свободно"}'; \
lspci 2>/dev/null | grep -i -E 'nvidia|vga|3d' ; nvidia-smi -L 2>/dev/null; \
echo "Docker: $(docker --version 2>/dev/null || echo нет)"; \
echo "Занятые порты:"; ss -ltn | awk 'NR>1{print $4}' | grep -E ':(8000|8080|8081|5432|11434)$' || echo "  8000/8080/8081/5432 свободны"; \
echo "Интернет: Docker Hub $(curl -s -o /dev/null -w '%{http_code}' https://registry-1.docker.io/v2/ || echo нет), PyPI $(curl -s -o /dev/null -w '%{http_code}' https://pypi.org/simple/ || echo нет)"

## Оперативная память

- `free -h` — общий объём, занятая и свободная память, использование swap (в человекочитаемом виде).
- `vmstat -s` — детальная статистика по памяти (кэш, буферы и т. д.).

## CPU (загрузка процессора)

- `top` — интерактивный мониторинг процессов: загрузка CPU, потребление памяти, время работы. Для выхода нажмите `q`.
- `htop` (если установлен) — удобный аналог `top` с цветной визуализацией и сортировкой по CPU/MEM.
- `mpstat -P ALL 1 5` (требуется пакет `sysstat`) — загрузка по каждому ядру CPU в течение 5 секунд с интервалом 1 секунда.

## Диск (свободное место)

- `df -h` — свободное и занятое место по файловым системам. Обращайте внимание на колонки `Available` и `Use%`.
- `du -sh /*` — суммарный размер основных директорий в корне.
- Для анализа конкретной директории (например, `/var`):  
  `du -h --max-depth=1 /var | sort -k1 -hr`
- Поиск больших файлов (от 100 МБ):  
  ```bash
  find / -type f -size +100M -exec ls -lh {} \; | sort -k5 -hr | head -n 10
## Нагрузка системы и процессы
uptime — средняя нагрузка (load average) за 1, 5 и 15 минут, а также время работы системы.
Load average сравнивают с количеством ядер: если значение заметно больше числа ядер — система перегружена.

Топ‑20 процессов по потреблению памяти:
ps aux --sort=-%mem | head -n 20
Топ‑20 процессов по потреблению CPU:
ps aux --sort=-%cpu | head -n 20
## Сеть
ss -tuna — активные TCP/UDP соединения и прослушиваемые порты.
sar -n DEV 1 10 (пакет sysstat) — трафик по интерфейсам: раз в секунду в течение 10 секунд.
## Если ВМ с GPU
nvidia-smi — загрузка GPU, использование видеопамяти, список процессов, использующих GPU.
Постоянный мониторинг
watch -n 1 "free -h && df -h" — обновление информации о памяти и диске каждую секунду.
Либо используйте top / htop в интерактивном режиме.
## Особенности при использовании Docker
Если на ВМ запущены контейнеры, системные команды (free, top) показывают ресурсы всей ВМ. Для оценки потребления по контейнерам:

docker stats — потребление CPU, памяти, сети и диска по контейнерам в реальном времени.
